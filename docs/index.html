✨ Key Features

🔍 Enhanced Search

Multi-stage retrieval system combining keyword matching and semantic search using sentence transformers for optimal document retrieval.

💬 Conversation Memory

Maintains conversation history with automatic summarization, providing contextual responses based on previous interactions.

🎯 Smart Query Expansion

Intelligent query expansion with negation handling, specifically designed for Chinese language queries and FAQ systems.

📚 Document Processing

Load and process Q&A pairs from text files with embedding-based similarity matching for accurate information retrieval.

🛠️ Quick Start

git clone https://github.com/Kan090808/rag_test.git cd rag_test
pip install -r requirements.txt
# Copy the configuration template cp config_template.py config.py # Edit config.py and add your OpenRouter API key # OPENROUTER_API_KEY = "your-api-key-here"
# Start the web interface python app.py # Or use the startup script python start_web.py
